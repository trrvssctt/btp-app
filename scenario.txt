• Tous les prix sont en FCFA (francs CFA ouest-africains, code XOF).
• Les numéros auto-générés (BR-2026-XXX, BC-2026-XXX, TRF-XXXX) peuvent
  différer si d'autres enregistrements existent déjà en base — l'important
  est de vérifier le comportement, pas le numéro exact.
• Les valeurs de stock "initial" sont celles injectées par seed_reel.js.
  Si le seed n'a pas été relancé récemment, les valeurs peuvent différer ;
  ajustez vos calculs en conséquence en lisant le stock réel avant de commencer.
• Le workflow demande complet est :
  BROUILLON → SOUMISE → VALIDATION_TECH → VALIDATION_BUDGETAIRE
  → VALIDATION_DIRECTION → APPROUVEE → (bon de commande) → RECEPTIONNE
